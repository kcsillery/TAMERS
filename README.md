# TAMERS survey analysis

This repository contains the data-processing, statistical-analysis, and figure-generation scripts for the TAMERS survey on climate-adaptive tree species choices among European forestry practitioners and researchers.

TAMERS is a project supported by the Velux Foundation and led by Dr. Katalin Csillery and the Evolutionary Genetics group at the Swiss Federal Research Institute WSL (Switzerland), Dr. Anastazija Dimitrova (Ss. Cyril and Methodius University in Skopje, North Macedonia), Dr. Tobias Schulz (WSL, Switzerland), Dr. Daniella Schweizer (WSL, Switzerland), in collaboration with Prof Dr Jürgen Bauhus (Albert-Ludwigs-Universität Freiburg, Germany), Dr Maria Hällfors (SYKE, Finland), and Robert Jenni (FOEN, Switzerland).

https://www.wsl.ch/en/projects/tamers/

Consult the survey here: https://limesurvey.wsl.ch/index.php/671593

The analysis is organized as a sequential pipeline. Only the starting data files are stored in the repository. Intermediate `.RData` objects and derived `.csv` files are generated by the scripts and should not be added manually.

## Software requirements

The analysis is written in R. The following packages are used across the scripts:

```r
install.packages(c(
  "readxl",
  "ggplot2",
  "openxlsx",
  "XML",
  "psych",
  "pals",
  "RColorBrewer",
  "maps",
  "vcd"
))
```

The main mixed-effects models also require **ASReml-R** (`asreml`). ASReml-R is licensed software and is not installed from CRAN. The analyses in the manuscript used ASReml-R v4.2.

All scripts assume that the repository root is the R working directory, so that files can be accessed using relative paths such as `data/...` and `figures/...`.

## Botanical illustrations in /species images

This folder contains the botanical illustrations used in the survey for the 30 pre-defined species. The images show characteristic morphological features, such as shoots and foliage, cones or other reproductive structures, seeds and/or seedlings, where applicable, to facilitate species recognition.

## Starting data files

To reproduce the complete workflow, the following files are required before any scripts are run.

### Survey and dissemination data

- `data/results-survey116296_all_02072026_anonymized.csv`  
  Anonymized LimeSurvey response export used for the main analysis. Note that the author de-identified raw survey data by replacing the IP addresses and responses provided to question G09Q27, revealing interdependency with participation in MyGardenOfTrees (https://www.mygardenoftrees.eu/home), and question G07Q33, where respondents could give their email addresses to be informed about survey results, with dummy answers for full reproducibility of the scripts.

- `data/TAMERS_dissemination_anonymized.xlsx`  
  Anonymized log of documented questionnaire dissemination actions. This file is used only by `0_dissemination_figure_bubbles.r`.

- `data/limesurvey_survey_116296_question_code.lss`  
  LimeSurvey survey structure used to recover question and answer codes.

### Species nativeness and forest-type data

- `data/Forest_species_nativeness_byCountry.csv`  
  Country-level nativeness of the 30 predefined tree species.

- `data/Forest_species_nativeness_byForestType.csv`  
  Association of the predefined species with the forest types used in the questionnaire.

### Translation and recoding tables

These files contain manually checked recoding of multilingual free-text or "Other" responses:

- `data/action_translation_codebook.csv`
- `data/support_translation_codebook.csv`
- `data/experience_translation_codebook.csv`
- `data/barriers_translation_codebook.csv`
- `data/infosource_translation_codebook.csv`
- `data/knowlneeded_translation_codebook.csv`

### Additional species proposed by respondents

- `data/OtherNativeness/other_species_broadleaf_codebook_checked.csv`
- `data/OtherNativeness/other_species_conifer_codebook_checked.csv`
- `data/OtherNativeness/Forest_Other_species_nativeness_byCountry.csv`

No intermediate `.RData` files are required at the start of the analysis.

## Analysis workflow

Run the scripts from the repository root in the order below. Each script reads either starting data or objects created by earlier scripts.

| Script | Purpose | Main derived files |
| --- | --- | --- |
| `0_dissemination_figure_bubbles.r` | Summarizes the geographical and temporal distribution of documented survey dissemination actions | `figures/SFig1_dissemination_efforts.pdf` |
| `1_data_cleaning.r` | Cleans the raw survey export, filters consent and incomplete entries, screens duplicate/repeat submissions, and creates the cleaned survey dataset | `data/dat_all.RData` |
| `2_create_codebook.r` | Creates a human-readable variable codebook from the cleaned survey dataset | `data/TAMERS_variable_codebook.xlsx` |
| `3_create_codes2.r` | Extracts LimeSurvey question and answer codes from the `.lss` survey file | `data/codes2.RData` |
| `4_demogr.r` | Recodes respondent characteristics, creates the respondent-profile figure, and prepares demographic variables for later analyses | `data/country_ftype.RData`, `data/dat_all_demographics.RData` |
| `5a_country_clustering.r` | Checks similarity among countries in the native-species composition of the predefined species set using Jaccard distance | diagnostic clustering figure |
| `5b_species.r` | Prepares country- and forest-type nativeness summaries and the nativeness figures | `data/Country_native_species_proportion.csv`, `data/Region_minimalist_native_species_proportion.csv`, `data/Region_native_species_proportion.csv`, `data/data_nativeness_heatmap.RData` |
| `6a_datasets_translations.r` | Recodes questionnaire variables and manually checked multilingual/free-text responses into analysis-ready variables | `data/dat_all_translated.RData` |
| `6b_datasets_scores.r` | Constructs the theory-driven experience, knowledge, management and governance scores used in the analyses | `data/dat_all_scores.RData` |
| `7_AMscore.r` | Calculates general willingness to plant and native-species preference scores, including checked additional species proposed by respondents | `data/dat_all_choice.RData` |
| `8a_models_revised.r` | Fits the bivariate mixed-effects model of the two species-choice scores and derives construct effects and regional BLUPs | `data/constructs_blups.RData` |
| `8b_models_figure.r` | Produces the main construct-effect and regional-BLUP figure | `figures/Fig4_Effects_in_attitude_space.pdf` |
| `9a_whyanswers.r` | Analyzes the perceived benefits and concerns accompanying species-specific planting decisions | species-reason figures and model summaries |
| `10a_species_model_revised.r` | Fits the respondent-by-species mixed-effects models of planting preference and derives species-specific effects | `data/species_model_results.RData` |
| `10b_species_maps.r` | Produces species-level effect plots and geographical predictions from the species model | `figures/Fig5_species_preferences_maps.pdf` |

`functions.r` contains helper functions shared by several scripts and is sourced where needed; it is not run as a separate analysis step.

The scripts can be run individually from R/RStudio or from a shell. For example:

```bash

Rscript 3_create_codes2.r
Rscript 4_demogr.r
```

## Notes on the data

The public survey export and dissemination log should contain only anonymized/de-identified information. Identifying fields used during internal duplicate screening are not intended for public release.

The dissemination dataset records documented dissemination **actions**, not the total number of people reached. Audience size was not consistently traceable for mailing lists, newsletters, websites, social media and onward forwarding, so dissemination intensity should be interpreted as documented recruitment effort rather than a complete measure of survey exposure.

## Reproducibility

For a fully reproducible run, execute the scripts in numerical order from a clean checkout of the repository. Derived `.RData` files are intentionally generated by the workflow rather than distributed as starting data.

Model estimates from `8a_models_revised.r` and `10a_species_model_revised.r` require access to ASReml-R.
